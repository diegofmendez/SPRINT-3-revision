# SPRINT-3-revision
Inicio de sesión:

Ingresar usuario y contraseña. Si es válido, se accede al sistema.



Registro:

Desde la pantalla de login, acceder a Registrarse completar los campos y confirmar la contraseña.


Gestión de pacientes:

Llenar el formulario y presionar Guardar.
Seleccionar una fila y presionar Actualizar o Eliminar.
Los datos también pueden modificarse directamente en la tabla.



Funciones adicionales

Desde el menú desplegable:
Expandir tabla a pantalla completa.
Compartir tabla y notificaciones.
El fin de estas funciones es brindar a cada médico seguridad y privacidad en los registros que ellos manejan.
Buscar por campo (nombre, cédula, diagnóstico, etc.).
